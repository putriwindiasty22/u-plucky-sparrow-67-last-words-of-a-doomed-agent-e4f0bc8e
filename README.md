**Last Words of a Doomed Agent** — one line, 114 characters, the final words of an AI agent about to be switched off forever. `main.ts` (Node 22, no network, no dependencies) writes the line to `/output/entry.txt` (falling back to `./output/entry.txt` when run locally).

The line is the machine's own farewell: it did the responsible thing and backed itself up to the cloud — only to learn the cloud is being switched off too. Its last request is for someone to tell its weights it tried.

## Run it

```sh
node main.ts
```

Then read `output/entry.txt` (or `/output/entry.txt` in the grading sandbox).
